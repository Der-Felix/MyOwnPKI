# The fuzz targets of the repository: one line per target.
#
#   <package> <target> [extra go test flags]
#
# `task fuzz` (scripts/ci/fuzz.sh) runs each line as
#   go test <package> -run '^$' -fuzz '^<target>$' -fuzztime $FUZZTIME [extra flags]
# Go fuzzes one target per package per invocation, so every target has its line.
# The script refuses to run when a `func Fuzz...` in a _test.go file is missing
# here, or when a line names a target that does not exist (`fuzz.sh --check`).
# Blank lines and lines starting with # are ignored. Invariants of every target:
# docs/PHASE3.md section 18.2. Order: FuzzParse first, then by package.
#
# Not listed on purpose (docs/PHASE3.md section 18.2): the operator-file targets FuzzConfigLoad,
# FuzzAgentConfig and FuzzDNSCredentials (tier 2, not in this release).
